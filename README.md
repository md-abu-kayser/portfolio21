# CSS Professional Notes

A modern, professional CSS knowledge base built for frontend engineers, designers, and technical teams.

This repository is a curated collection of advanced CSS notes, practical layout patterns, architecture guidance, and modern browser-ready techniques. It is structured for fast reference, team onboarding, interview preparation, and continuous learning.

## Why this repository matters

- Provides a complete, structured learning path from browser fundamentals to advanced layout architecture.
- Covers the latest CSS capabilities for 2025–2026, including container queries, view transitions, CSS nesting, modern color systems, and layout APIs.
- Includes real-world project patterns, debugging workflows, accessibility best practices, and performance optimization guidance.
- Designed for professionals who want a reference that is deep, practical, and easy to navigate.

## What you will find here

The repository is organized into a logical curriculum of topics:

- `00-prerequisites`: browser rendering, HTML basics, developer tools, and the CSS cascade
- `01-fundamentals`: syntax, selectors, inheritance, the box model, sizing, and shorthand usage
- `02-selectors-and-combinators`: selector depth, attribute selectors, pseudo-classes, and performance considerations
- `03-layout-and-positioning`: display modes, positioning, floats, stacking context, overflow, and centering strategies
- `04-flexbox`: container and item properties, alignment, wrapping, and practical flex patterns
- `05-css-grid`: grid fundamentals, template definitions, auto-placement, alignment, and layout decisions
- `06-responsive-design`: media queries, mobile-first workflows, fluid typography, responsive images, and modern viewport units
- `07-typography-and-fonts`: font loading, variable fonts, text layout, and accessible typographic systems
- `08-colors-and-backgrounds`: color models, gradients, theming, blend modes, and transparency techniques
- `09-borders-and-shadows`: shapes, borders, outlines, shadows, and visual depth effects
- `10-transforms-and-animations`: transforms, transitions, animation timing, motion performance, and motion reduction
- `11-advanced-selectors-and-logic`: `:is()`, `:where()`, `:has()`, structural selectors, and query-based logic
- `12-css-custom-properties`: theming, cascading variables, dynamic updates, and advanced fallback patterns
- `13-css-architecture-and-methodologies`: BEM, OOCSS, SMACSS, ITCSS, utility-first design, CSS Modules, and naming conventions
- `14-preprocessors-and-postcss`: Sass fundamentals, PostCSS workflows, autoprefixing, and migration strategies
- `15-css-frameworks-and-libraries`: Bootstrap, Tailwind, Bulma, Chakra, component libraries, and selection guidance
- `16-performance-optimization`: critical CSS, minification, unused CSS removal, layout thrashing, and audit strategies
- `17-modern-css-features-2025-2026`: container queries, modern color functions, `:has()`, `@scroll-timeline`, and other emerging standards
- `18-print-and-paged-media`: print stylesheet strategies, page rules, and advanced paged media control
- `19-cross-browser-compatibility`: resets, vendor prefixes, feature queries, polyfills, and testing strategies
- `20-accessibility-and-css`: contrast, focus management, reduced motion, screen reader-friendly techniques, and ARIA integration
- `21-testing-and-debugging`: visual regression, browser devtools, CSS unit testing, and common issue resolution
- `22-real-world-projects`: production-ready examples, project patterns, responsive layouts, dashboards, dark mode, and UI components
- `23-code-snippets`: reusable CSS patterns and snippet reference material
- `24-resources-cheatsheets`: curated learning resources, study aids, interview questions, and cheat sheets
